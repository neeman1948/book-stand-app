# אפליקציית דוכן ספרים

## עדכון אחרון

- דפי הלקוח עוצבו מחדש בהשראת הדף בביס 44: רקע ירקרק בהיר, כותרת מרכזית גדולה וכרטיסי פעולה צבעוניים וברורים לטאבלט.
- בדף הלקוח שם העסק מוצג כ"נאמן ספרים", בלי טקסט פתיחה ארוך.
- חיפוש ספר מציג מחיר במסך נקי ולא פותח את מסך סריקת הברקוד.
- לחיצה על "לתשלום / אני קונה" פותחת חלון עם QR ל-Bit, פרטי בנק ושדה קל לסימון איזה ספר נקנה.
- הורדת מלאי מתבצעת רק אחרי לחיצה על "שילמתי וקניתי".
- חזרה ממסך מחיר מחזירה למסך הקודם, למשל למסך החיפוש.
- בהזמנות ספרים נוסף הסטטוס "הוזמן", הוסרה מחיקה גורפת של כל ההזמנות, ונוספה הסרה להזמנה בודדת.
- במסך הזמנת ספר אפשר לחפש ספר קיים וללחוץ "להזמין את הספר הזה".
- בניהול נוסף אזור "מה נקנה" שמציג רכישות, הכנסה משוערת, ספרים מובילים ומלאי נמוך.
- טבלת ניהול הספרים הוקטנה כדי לראות יותר ספרים בבת אחת, כולל עמודת "נמכרו".
- בניהול ספרים אפשר להוסיף ולהסיר קטגוריות, ולסמן ספר כ"ספר במבצע".
- הניהול חולק ללשוניות, ונוספה תצוגה רצה אוטומטית לטאבלט עם מבצעים, ספרים ושקופיות ידניות.
- פרטי תשלום ואודות הועברו לסוף דף הניהול והוקטנו מאוד.

אפליקציית ווב פשוטה לטאבלט בדוכן ספרים:

- לקוח יכול לסרוק ברקוד, לחפש לפי שם ספר/מחבר/ברקוד, לראות מבצעים, לראות ספרים חדשים ולהזמין ספר חסר.
- החיפוש מציג השלמות מיד כשמתחילים להקליד.
- תוצאת ספר מציגה שם, מחבר, מחיר לקוח, מחיר קודם אם קיים, מלאי, הערות ותמונה אם הוגדרה.
- לחיצה על "לתשלום / אני קונה" פותחת פרטי תשלום, ורק אחרי "שילמתי וקניתי" יורדת יחידה מהמלאי.
- הזמנת ספר כוללת שם ספר, שם לקוח, טלפון והערות.
- אפשרויות תשלום מוצגות בחלון מידע: QR ל-Bit, פרטי העברה בנקאית והסבר נוסף.
- בעל העסק מנהל ספרים, מבצעים, בקשות, תשלום ואודות.
- בעל העסק רואה בניהול מה נקנה וניתוח בסיסי של מכירות ומלאי נמוך.
- עריכת ספרים ומבצעים נעשית דרך חלון עריכה, לא ישירות מתוך הטבלה.
- לכל ספר אפשר להגדיר מחבר, קטגוריה, תמונה, הערות, מחיר קודם, מחיר מכירה וסימון "ספר חדש".
- בניהול ספרים יש סידור לפי תאריך הוספה, א-ב, מחבר, מחיר, קטגוריה וחדש/לא חדש.
- ללא הגדרה חיצונית האפליקציה עובדת במצב הדגמה מקומי בדפדפן.
- עם Supabase האפליקציה מסתנכרנת בין הבית לדוכן בזמן אמת.
- בכל פתיחת אפליקציה נשמר גיבוי פנימי של הנתונים בדפדפן.
- ייצוא הנתונים מוריד JSON שכולל ספרים, הזמנות, הגדרות וגיבויים.

## הפעלה מקומית

לסריקת מצלמה עדיף להשתמש בכתובת `localhost`, כי דפדפנים חוסמים מצלמה בקבצי `file://`.

ב-Windows אפשר להריץ:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-local.ps1
```

ואז לפתוח:

```text
http://127.0.0.1:8765/
```

## חיבור Supabase

1. צרו פרויקט Supabase.
2. הריצו את `supabase-schema.sql` ב-SQL Editor.
3. הפעילו Realtime לטבלאות `books`, `book_orders`, ו-`settings`.
4. מלאו ב-`config.js`:

```js
window.BOOK_STAND_CONFIG = {
  supabaseUrl: "https://YOUR_PROJECT.supabase.co",
  supabaseAnonKey: "YOUR_ANON_KEY",
  tables: {
    books: "books",
    orders: "book_orders",
    settings: "settings",
    sales: "sales"
  }
};
```

בגרסת הפיילוט הזו אין כניסת מנהל וסיסמה. לפני שימוש ציבורי אמיתי כדאי להוסיף אימות והרשאות Row Level Security כדי שרק בעל העסק יוכל לערוך מחירים, מלאי, תשלום ואודות.

## הערה על תמונות

במצב מקומי אפשר להעלות תמונת ספר והיא נשמרת בדפדפן כמידע מקומי. בשימוש אמיתי עם Supabase כדאי להעלות תמונות ל-Supabase Storage או לאחסון תמונות אחר ולשמור בשדה הספר רק את הקישור לתמונה.

## קבצי המשך עבודה עם Codex

נוספו קבצי תיעוד כדי שלא נצטרך להסביר את כל הפרויקט מחדש בכל שיחה:

- `PROJECT_BLUEPRINT.md` - מפת דרך: מה יש בפרויקט, מבנה נתונים ומה כדאי לעשות בהמשך.
- `CONTEXT_SUMMARY.json` - תקציר קצר שמומלץ לתת ל-Codex בתחילת שיחה חדשה.
- `CHANGELOG.md` - יומן שינויים מסודר.
- `CODEX_WORKFLOW.md` - איך לבקש שינויים בצורה שחוסכת זמן וטוקנים.
- `FUNCTION_REFERENCE.md` - מפת פונקציות שמסבירה מה כל חלק מרכזי בקוד עושה.

בתחילת עבודה חדשה עם Codex, כתבו:

```text
אנחנו עובדים על אפליקציית דוכן ספרים. קרא קודם את PROJECT_BLUEPRINT.md, CONTEXT_SUMMARY.json, FUNCTION_REFERENCE.md ו-CHANGELOG.md מתוך outputs/book-stand-app, ואז תמשיך מהמשימה שאבקש.
```

## גיבויים

האפליקציה היא אתר שרץ בדפדפן, ולכן היא לא יכולה ליצור בשקט קובץ על שולחן העבודה בכל פתיחה. במקום זה היא שומרת גיבויים פנימיים ב-`localStorage` תחת המפתח `bookStand.backups`, עד 20 גיבויים אחרונים.

כדי לשמור גיבוי כקובץ במחשב, נכנסים לניהול ולוחצים `ייצוא נתונים`. הקובץ שיירד כולל גם את הגיבויים הפנימיים.
